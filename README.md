# PANCAKE AXEL

Three.js + TypeScript + Viteで動く、60秒のパンケーキ空中演技ゲーム。
外部API、有料アセット、サーバー、外部フォントは不使用。モデル・焼き色テクスチャ・効果音はプログラムで生成します。

## 起動

```sh
npm ci
npm run dev
```

## 操作

- 「生地を注いで、スタート」で開始。2.6秒の注ぎ演出後、60秒の競技開始。
- トスボタンまたはSpaceを長押しして離す。長くためると滞空時間が伸びます。
- 空中で縦回転（J）、ひねり（K）。追加回転の完了後に再入力できます。
- 左右ボタン、矢印キー、画面のドラッグでフライパン移動。着地前に中央で受けます。
- モーションは開始画面で任意に有効化。左右の傾きで移動と角度調整、加速度と手首の回転速度の組み合わせでトス、空中の前後の傾きで縦回転、左右のひねりで横回転。端末を投げないでください。
- 楽な持ち方を水平として校正。水平から14度以内は着地準備OK。水平に戻すとフライパンが落下位置に寄るアシストが働きます。大きく傾いたままの着地は減点。
- ひねりと縦回転は一度ニュートラルに戻すと再入力可能。入力の平滑化と待機時間で誤検知を抑制。同じトス中の追加回転は最初の方向を維持します。
- 縦持ち・横持ちの座標を補正。途中で画面の向きを変えると一時停止して再校正。左手モードと感度調整あり。
- 空中で「キャッチ」をタップすると位置・水平の着地補助。タップだけのトスも可能。
- 権限があっても実際のセンサーデータを受信できなければタッチ操作。データが途切れた場合もタッチに自動切り替え。
- 一時停止画面で水平校正と感度設定。タブ非表示・フォーカス喪失でも自動停止。

## 採点と仕様

技術・芸術とも1000点上限、総合は `round(sqrt(技術 × 芸術))`。
技術点は技の難度 × 着地品質 ÷ (1 + 同じ技の既出回数 × 0.45)。
芸術点は表裏の焼成品質の幾何平均 × 形の保持率 × 1000。
各面20秒が理想。20秒超過で品質が低下し34秒で0。空中では焼けません。
トスは必ず半回転して裏返り、縦回転入力で追加の1回転、ひねり入力で横方向の1回転。
着地時の回転不足・位置ずれで技術点と形の保持率が低下。生地投入直後の3秒未満のトスも形が崩れます。
制限時間内に着地できなかった演技は加点せず、形の保持率を減らします。
投げ続けると生焼け、放置すると焦げ、焼くだけでは技術点0。バランスよく焼いて複数の技を使う必要があります。

企画書の暫定5演技制は今回の要望に合わせて時間制に変更。
オンラインランキング・リプレイ・音声実況は未実装。ベストスコアは端末内保存。
シェアはWeb Share API、非対応時はクリップボード、X投稿リンクを用意。
センサーはHTTPSと実機権限が必要。未対応・拒否時もタッチでプレイ可能。
モーションの感度と端末差はiOS/Androidの実機検証が必要です。

## GitHub Pagesへ公開

1. このフォルダをGitHubの公開リポジトリのmainブランチにpush。
2. リポジトリの Settings → Pages → Source を GitHub Actions に設定。
3. Actionsの「Deploy to GitHub Pages」を実行（以後mainへのpushで自動公開）。

Viteのbaseを相対パスにしているため、リポジトリ名付きURLにも対応。
GitHub Freeの公開リポジトリと標準のPages URLを使用すれば有料サービス不要。
公開先: https://cadmium2525.github.io/pancake/
リポジトリ: https://github.com/cadmium2525/pancake
mainへのpush後、Actionsが成功すると公開サイトに反映されます。

## 検証

```sh
npm test
npm run build
npm run preview
```

採点・焼成・時間切れ・現実的な金メダル到達経路を自動テスト。
UIとWebGLの確認は実ブラウザで実施。ソースはsimulation（ゲームルール）、render（描画とカメラ）、main（入力とUI）に分離。
